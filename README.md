#  Netflix Data Analysis Project

##  Project Overview
This project focuses on analyzing Netflix movies and TV shows data to discover trends, patterns, and insights about content available on the platform. The analysis explores different aspects such as genres, cast members, ratings, release years, and content types.

##  Tools Used
- **SQL** – for querying and analyzing structured data  
- **Excel** – for data cleaning and preparation  
- **Power BI** – for building interactive dashboards and visualizations  

##  Dataset
The dataset includes information about Netflix titles, such as:
- Title  
- Type (Movie or TV Show)  
- Cast  
- Country  
- Release Year  
- Rating  
- Duration  
- Genre (Listed In)  

##  Key Analysis Performed
During this project, I explored the data to answer questions like:

- How many Movies vs TV Shows are on Netflix  
- Which years had the most content releases  
- Most common ratings (TV-MA, PG, etc.)  
- Most frequent genres on Netflix  
- Countries producing the most Netflix content  
- Popular actors appearing in multiple titles  

##  Dashboard & Visualizations
Using **Power BI**, I created interactive dashboards to visualize:

- Content distribution by type  
- Release trends over time  
- Top genres and ratings  
- Country-based content production  

Dashboard screenshots can be found in the project files.

##  Skills Demonstrated
- Data Cleaning and Preparation  
- Writing SQL queries for data analysis  
- Working with real-world datasets  
- Data visualization and storytelling using Power BI  
- Extracting insights from entertainment industry data  

##  Project Goal
The goal of this project is to demonstrate practical data analysis skills by working with a real dataset and turning raw data into meaningful insights using multiple tools.
